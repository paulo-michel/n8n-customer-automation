# Automação de Clientes com n8n

## Objetivo

Automatizar a integração de dados utilizando n8n.

## Tecnologias

- n8n
- Webhooks
- HTTP Request
- PostgreSQL
- Git
- GitHub

## Fluxo

Webhook
↓
Validação
↓
Processamento
↓
Banco de Dados
↓
Resposta

## Como executar

1. Importe o arquivo JSON no n8n.
2. Configure as credenciais.
3. Execute o workflow.
